# Generador de Planillas y Gestión de Territorios

## Descripción
Sistema con backend en FastAPI y frontend estático para gestión de territorios, asignaciones y autenticación con JWT.

## Estructura
- backend/: API FastAPI
- frontend/: interfaz web
- scripts/: utilidades y procesamiento offline
